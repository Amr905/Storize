## 3. Ints
Kept ints in fixtures: `taken_at` (18), `latest_reel_media` (19), `expiring_at` (1), `caption`/media `created_at`-class values, `like_count` (4, 4-5 digits), `play_count` (1), widths/heights, DASH `bandwidth` and segment `end` values (6-7 digits), one `duration_in_ms`-class int. Assessment:
- **No id-class int survives.** The one `pk` int (10 digits) is under the location object and does **not** equal the raw value (raw is 9 digits); no user, media or viewer id is a raw value. Commenter and viewer ids are `user_N`.
- **Low (L1):** `latest_reel_media` appears under 10 commenter user objects (`preview_child_comments[].user`) plus 5 other user objects. It is the time of that person's latest story and could be matched with an observer's own story-tray history within the 24 h window. Weak, but it is a per-person value; recommend dropping or rounding it for non-owner users.
- **Info:** like and play counts and `taken_at` are public account data (Lead already accepted).
- **Info:** DASH segment `end`/`bandwidth` ints are encoder properties, not identifying.
