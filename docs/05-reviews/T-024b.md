### Findings
| ID | Sev | Finding |
|----|-----|---------|
| F-1 | Info | `thumbNew`, `thumbSelected` and `collapse` are still unused. Recommendation: **keep** them, each with an `@key` description (already present) that says which task consumes it (`thumbNew` / `thumbSelected` for T-027 thumbs, `collapse` for T-038 a11y or the expandable StepCard). Deleting them would discard wording already reviewed. Add a pointer to the ARB description or the T-027 / T-038 task notes, and do not leave them dangling without a consumer past T-038. |
| F-2 | Low | Counts and numbers are interpolated as raw `'$count'`, `'$digit'`, `'${widget.number}'` and `'+$hidden'`. This is not localised: for an Arabic locale (RTL readiness) the digits stay Western and the `+N` overflow chip is not an ARB key. Suggest `NumberFormat` or an ICU `{count, number}` key (`chipOverflow`) when adding `ar`. Not a T-024b regression, since the strings were already literals. |
| F-3 | Low | 12 older keys (`emptyNoData*`, `emptyFiltered*`, `error*Title/Body`) have no `@key` description (from T-025, outside the T-024b scope). Add descriptions when the keys are next touched. |
| F-4 | Info | `git diff main` shows unrelated storize_data test and status-doc changes only because `main` moved on. Against the merge-base the branch touches only app/l10n, app/ui and app/test. |
